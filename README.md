# 枫叶修图 · Photo Studio

[![CI](https://github.com/qianc7001-coder/photo-studio/actions/workflows/ci.yml/badge.svg)](https://github.com/qianc7001-coder/photo-studio/actions/workflows/ci.yml)

[![Tests](https://img.shields.io/badge/tests-3669%20passed-brightgreen.svg)](#测试)

给摄影师用的**局部修图**工具：在照片上框选任意区域，交给生图模型修改，结果自动贴回原位置。

**核心特点**：结果无缝融合，非破坏性可调，保留拍摄信息。

> 最新版本 **v3.5.5** · [下载 APK](https://github.com/qianc7001-coder/photo-studio/releases/latest) · [更新日志](CHANGELOG.md)

---

## 它解决什么问题

传统流程：导出照片 → 用别的工具涂涂抹抹 → 再导入 → 手动对齐 → 接缝对不上。

枫叶修图的做法：

```
打开照片 → 框选要改的地方 → 写一句要求 → 生成 → 自动贴回原位置
```

贴回时做了**边缘羽化**和**接缝色彩匹配**，所以看不出拼接痕迹。

## 功能

### 首页 · 修改历史
- 打开应用先看到**修过的照片**（按 今天 / 昨天 / N 天前 分组），而不是一块空白画布
- 点任意一条**接着改**，或点右上角「修新照片」
- 工具栏默认收起，进入编辑页才展开 —— 手机竖向空间全给画布
- **返回键逐级退**：有浮层先关浮层（作品预览 → 设置/记录/历史/修改记录/照片信息/导出 → 对比图 → 失败说明），
  生成中先取消生成，画笔/平移/引导线模式退回框选，编辑中退回首页，已在首页才退出应用
- 退回首页前会**先把当前作品存进修图记录**，随时可以从首页点回去继续编辑
- **工具栏高度可自由调节**：拖动底栏手柄拉到任意高度，轻点手柄或箭头收起/展开；
  高度会被记住，换图、重启都沿用
- 工具提示（画笔/引导线怎么用）**只显示一次**，第二次进入不再弹出

### 顶栏
- 顶栏只留 5 个高频入口：**打开 / 撤销 / 重做 / 导出 / 更多**
- 「照片信息 / 修图记录 / 设置」收进右上角**「更多」菜单** ——
  原来 7 个按钮的固定占宽是 344px，360px 的手机上文件名被压到只剩几个像素，
  320px 的机器上按钮还会溢出屏幕右边缘；收起来后降到 252px，任何机型都放得下
- 点菜单外面任意位置、或按返回键都会收起菜单；点菜单里的一项会先收起菜单再打开面板

### 工具栏高度：无级调节
- 捏住工具栏上方的手柄**上下拖动**，松手停在哪里就是哪里 —— 不再一松手就弹到
  「收起」或「展开」两档
- 想同时看到「工具行 + 参数条」这种中间高度，拖到那儿松手就行；拖动过程连续跟手
- 拖出来的高度会**记住**：换照片、退出重进都沿用
- **轻点手柄**仍然是一键收起/展开（这个离散动作保留，和无级拖动互不干扰）

### 没框选？那就改整张图
- 打开照片后**不框选**，直接点 AI 生图、调色、画笔或引导线，都会作用在**整张图**上
- 界面会明确显示「**整张图 W×H**」，成本预估照常给出 —— 不会让你在不知情的情况下改全图
- 整图生图时提示词自动换成「以这张照片为基础做整体调整」的口径，
  不再说「这是一张照片的局部裁切」（否则模型会把边缘当参考、缩着改中间）
- 想只改局部时，照旧先框选；框选后行为与以前完全一致
- 整张图**没有「周围环境」**，所以自动关掉边缘羽化与无缝融合 ——
  否则会出现「四周留一圈没改」和「凭空多出一个暗角」

### 编辑
- **自由框选**：任意位置、任意大小，支持拖拽手柄调整、锁定比例
- **画笔**：涂抹标记"这里不要动"（默认整块都会改）
- **引导线**：只有两类 —— **直线** 和 **自由绘制**
  - 两种线**都会画进发给模型的图片**。这是关键：只把线翻译成文字时
    （「地平线在画面高度 62% 处」）模型只能靠猜落位，偏个 10% 很常见 ——
    模型看不到我们的坐标系，但看得见图
  - **直线**：拖一条，告诉模型「地平线 / 立柱 / 道路应该在这里」。
    方向由你手画的角度决定（不需要先声明它是横的还是竖的）；
    小斜角会**自动吸附**到水平/垂直（12° 内），透视下的斜线则保留原角度
  - **自由绘制**：手画一笔，告诉模型「头发 / 水流 / 衣褶往这个方向走」。
    **不做方向吸附**（拉直会毁掉手画的弧度）
  - **颜色按画的顺序自动分配**：第 1 条红、第 2 条青、第 3 条黄…
    （红→青→黄→品红→绿→橙，六色循环）。提示词里逐条指代
    「第 1 条（红色，直线）从横向 18%、纵向 51% 延伸到…」，指代唯一。
    颜色**故意不让你选** —— 两条红线时「红线」这个词就废了，等于引导线白画
  - 删除中间某条线**不会**让其它线换色；新画的线补上空缺的颜色而不是撞色
  - 设置里可**一键关掉「引导线画进请求图」**：万一某个模型把线也画进了画面，
    关掉后引导线退化成纯文字说明
  - 位置换算到请求图坐标时**补偿上下文外扩**；越界部分被真正裁掉
    （不能压到边缘，否则模型会看到一条沿边缘的假线）；点一下即可删除
- **缩放平移**：双指缩放、拖拽平移，最高 12 倍放大

### 非破坏性
- **修改记录面板**：每次生成是一条独立记录
- 可随时调整**效果强度 / 边缘羽化 / 色彩匹配**，**不需要重新生成**（不花钱）
- 可**临时关闭**某次修改做前后对比，可**删除**中间任意一次

### 统一撤销
画笔、删除、调参、开关**全部可撤销/重做**（100 步历史）。

### 修图历史
- **完整时间线**：按顺序列出做过的每一步，每步带摘要（改了什么、当时有几处修改、几点做的）
- **预览任意一步**：点时间线上任意位置，画面真的回到那一刻，先看效果再决定
- **一键跳回**：确认后回到选中的那一步，后面的步骤被撤销（确认前随时能跳回来）
- 不存图片快照，只复用撤销记录 —— 100 步历史几乎不占额外内存

### 修图记录（跨天作品库）
- 修过的每一张照片**自动留档**，关掉应用、第二天打开仍然在
- 按 **今天 / 昨天 / N 天前 / 具体日期** 分组，一眼看出哪些是昨天修的
- 每条带缩略图、文件名、修改处数、当时时刻
- 点开看大图，只要编辑数据还在就能 **继续编辑这张** —— 直接回到当时状态接着改
- 同一张照片反复修改**只占一条**（原地更新）
- **能留住多张**：底图按需缩到 2048px 以内再存（只缩不放），记录可以有很多条。
  早期版本把 3072px 底图原样编码进浏览器存储，UTF-16 下约 4.15MB，
  超过 2.5MB 的容量上限 —— 于是每存一张就把上一张挤掉，表现成「历史记录只能保存一张」
- 空间不足时**分两级淘汰**：先降级旧记录的底图（保留预览与列表），真的放不下才淘汰整条。
  **正在编辑的那张永不被淘汰**，并明确提示

### 后台保活
- 生图要 30~60 秒，切走或锁屏时系统会回收进程 —— **请求断了但钱已经花了**
- 生成期间自动开启前台服务把进程钉住，切走也能拿到结果（空闲即停，不留常驻通知）
- 生成完成后发通知告诉你「好了」，不用反复切回来查看
- 可选「一直保活」开关，连续修图时不用每次等系统调度
- 设置里可一键跳转到系统的「电池优化白名单」—— 各家 OEM 后台策略不同，这是唯一通用入口
- **兼容 Android 5.0 ~ 14**：所有系统接口按版本分流（通知渠道 / 前台服务类型 / 运行时权限），老设备走降级分支而不是崩溃

### 环境契合提示词（与融合互补）
- 每次请求前先**测量选区周围**：亮度档位、冷暖色调、反差强弱、主光方向
- 把测出来的结果**写进提示词**，模型就有了可对照的目标（而不是只收到「请保持一致」）
- 附带行为约束：不改周边、边缘不出现可见边界、不加边框暗角、要像一次拍摄
- 与无缝融合分工：**提示词让模型尽量做对，融合兜住剩下的残差**
- 可在设置里关闭；不额外调用模型（免费）

### 后台生图（不用干等）
- 生图要 30~60 秒，**不必盯着屏幕**：提交后可以直接回首页，或者去修下一张照片
- 画布上方的状态条显示「几张在跑 / 几张好了」，随时看得见进度
- 跑完**自动存回它自己那张照片**的记录里（不是当前这张），并弹系统通知
- 再打开那张照片时结果**直接就在图上**，不需要手动贴回
- 每张照片的生成任务各自持有自己的**输入快照**（底图 + 选区 + 引导线），
  所以切走后接着改别的照片不会串味
- 任务只在**内存**里记 —— 进程被杀就说明请求已经死了，留个假进度条反而更误导

### 基础调色（AI 改完之后的那点色差）
- **曝光 / 对比度 / 饱和度 / 色温 / 色调** 五个滑块，对着 AI 刚改的那块做色调微调
- **只作用在框选区域内**，选区外一个像素都不动（逐像素校验）
- 实时预览、随时撤销、**不消耗调用次数**（纯本地数学，不花钱）
- AI 结果贴回后**自动打开**，不用再去找入口；正在用画笔或引导线时不会抢走工具栏
- 实现是线性光曝光 + 中灰对比度枢轴 + Rec.709 饱和度 + 通道增益白平衡，
  不是简单乘系数，避免出现「一拉对比度就偏色」

### 调用日志
- 设置里可查看**每次模型调用**的时间、耗时、成功与否、花费，失败时带具体原因
- 顶部显示汇总：调用次数与累计花费
- 可**导出成文本或 JSON**（走和图片一样的原生保存通道，能看到真实路径）
- 只保留最近 **100 条**（环形缓冲），不会无限撑大存储

### 新手教程
- 首次打开走一遍**六步引导**：选框 → 生图 → 贴回 → 调色 → 导出 → 历史
- 高亮当前该点的按钮并配一句话说明，可上一步/下一步/跳过
- 跳过、点遮罩、按返回键都记为已看过；之后可从设置里重看
- 「重置工具提示」**不会**连教程一起重置（两件事分开记）

### 无缝融合（解决「生成块和周围不契合」）
- 提示词只能**请求**一致，模型看不到你照片的像素统计 —— 所以总差一点
- **光照渐变对齐**：拟合周围的光照走向（如「左亮右暗」），按同样梯度调整生成块
- **对比度对齐**：模型出图常偏灰或过艳，按周围的明暗起伏自动校正
- **颗粒补偿**：模型输出比真照片平滑，接缝处补上相当强度的颗粒
- **契合度评分**：每个图层显示 0~100 分和具体问题，调参数时能看出有没有变好
- **整张图时自动关掉**：融合的全部依据是「选区外一圈的周围环境」，改整张图时没有外圈可采样。
  这时不做校正、也不报契合度 —— 整张图没有接缝，报「接缝处有色差」是假警报；
  硬算还会把空样本当成纯黑，把整幅图压黑成一个暗角
- 全部即时生效、**不重新调用模型**（不花钱）
- **中心区域不做色调对齐** —— 你改的颜色完整保留，融合只修接缝的技术性瑕疵

### 自动检查更新
- 启动时自动向 GitHub 查询最新版本（每 12 小时最多一次，失败会退避，最多退到 48 小时）
- 发现新版本时弹出提示条：可**一键更新**（系统下载 + 自动调起安装器）、查看更新内容、或忽略此版本
- **忽略只针对那一个版本** —— 出了更新的版本仍会提示，不会从此收不到更新
- 设置里可手动检查，显示上次检查时间与远程版本号，也可关闭自动检查
- 实现上**不用 `/releases/latest`**（它按创建时间判定，补发旧版本后会指向旧版本），而是拉完整列表按版本号挑最高
- 请求经本地代理转发时显式声明 **GET** 并补 **User-Agent** —— GitHub 的版本列表用 POST 会返回 401、
  缺 UA 会被 403，两者都会让「检查更新」静默失败
- 代理不可用时**自动回退直连**（与生图路径一致），不会因为代理异常导致功能整个不可用

### 画质
- 边缘羽化（消除拼接硬边）
- 接缝色彩匹配（把生成结果色调对齐原图）
- 细长选区自动按比例裁切贴合，**不会变形**
- **整块一次生成** —— 选区再大也整块发送，从根上避免接缝
- 小选区自动放大后发送（应对接口最小尺寸限制）

> **关于分块**：早期版本会把大选区切成多块分别生成，但每块是模型**独立生成**的，
> 重叠区内容必然不完全一致，加权平均后接缝处会出现重影或发糊 ——
> 这是分块方案本身的固有缺陷，不是参数能调好的。
> **该功能已在 v3.2.0 彻底移除**：现在无论选区多大都整块一次生成，
> 成本也从「按块数翻倍」回到固定一次。老配置里残留的分块字段会在升级时自动清除。

### 照片信息
- 一键看清这张照片的**机型、镜头、快门、光圈、ISO、焦距、拍摄时间**（直接读 EXIF）
- 同时显示尺寸、像素数、文件大小、色彩配置（sRGB / 广色域）
- 含 GPS 时**只提示「有定位信息」**，不显示坐标 —— 避免截图泄露位置

### 元数据
- 导出保留 **EXIF**（相机、镜头、光圈、快门、ISO、拍摄时间）
- 保留 **ICC** 色彩配置
- 手机竖拍照片的旋转标记正确归一化（不会二次旋转）
- 社交分享时可**自动移除 GPS 定位**（保留其他信息）

### 导出设置
- 点顶栏的导出按钮弹出面板：**格式**（JPEG / PNG）+ **大小**（原始 / 4096 / 3000 / 2400 / 2000 / 1600 / 1080 / 自定义长边）
- 实时显示**输出尺寸**与**预计体积**，导出前就知道会得到多大的文件
- **只缩不放** —— 选 4000px 但原图只有 1600px 时按 1600px 输出，并说明原因（放大只会变糊）
- 可单独控制是否保留拍摄信息 / 定位信息 / 色彩配置
- 面板里的选择会被记住，下次打开还是这一套；但**不影响**设置页里选的交付预设
- 所有滑块**只能拖动圆点调节**，点轨道不会跳位 —— 设置里滑动时容易误触跳变

### 稳定性
- 编辑历史内存上限（默认 192MB，可调）—— 防止手机被系统杀掉
- 编辑进度自动保存 —— 应用被回收后可恢复
- 会话恢复包含**选区、画笔掩膜、引导线**（含每条线的颜色）—— 切后台回来接着画
- 导出预设（客户交付 / 微信 / 小红书 / 网页 / 无损交接）

### 模型接入
- 多服务商：硅基流动 / OpenAI / 任意 OpenAI 兼容接口
- **自动检测可用模型**（自动筛出支持参考原图编辑的模型）
- **成本预估**：生成前显示花费，大额自动确认
- 失败原因诊断（区分模型选错、没收到图片、Key 失效、限流、尺寸不合规等）

## 快速开始

### 方式一：安装 APK（推荐）

1. 安装 `枫叶修图.apk`（Android 7.0+）
2. 打开应用 → 右上角「设置」
3. 填「接口地址」和「API Key」
4. 点「自动检测可用模型」，选一个标着**可编辑**的模型
5. 回主界面：打开照片 → 框选 → 写要求 → 点「生成并贴回」

**推荐模型**（支持参考原图编辑）：

| 服务商 | 模型 | 单价参考 |
|---|---|---|
| 硅基流动 | `Qwen/Qwen-Image-Edit` | $0.04/张 |
| 硅基流动 | `black-forest-labs/FLUX.1-Kontext-pro` | $0.04/张 |
| OpenAI | `gpt-image-1` | $0.042/张 |

> 注意：像 `deepseek-chat`、`gpt-4o` 这类是**对话模型**，只会回文字，不能用于修图。

### 方式二：浏览器打开（无需安装）

```bash
node app/server.js 8788
# 然后用手机浏览器打开 http://127.0.0.1:8788
```

或直接打开 `dist/枫叶修图.html`（单文件版，离线可用）。

## 从源码构建

### 环境要求

- **Node.js** 18+
- **JDK 17**（`apt install openjdk-17-jdk-headless`）
- **Android 工具**：`apt install aapt zipalign`，另需 `d8.jar` / `apksigner.jar` / `android.jar`
  （来自 Android SDK build-tools 与 platform，放在 `/root/android-sdk`，可用 `ANDROID_SDK` 环境变量覆盖）

### 构建

```bash
# 构建 APK（自动递增版本号）
bash tools/build-apk.sh

# 只构建单文件 HTML
node tools/build-single.js

# 版本号检查（不改文件）
node tools/bump-version.js
```

### 架构说明

**为什么 Android 版内置一个 HTTP 服务？**

WebView 里用 `file://` 打开页面时，跨域请求会被拦截，而且 `localStorage` 的源不稳定（随机端口会导致设置丢失）。

所以应用启动时在 `127.0.0.1` 起一个**只监听本机**的极简 HTTP 服务：
- 页面与接口同源 → 没有跨域问题
- 固定端口 → 设置能稳定保存
- 生图请求由本机服务转发 → API Key 不经过第三方

## 设计要点

### 贴回为什么看不出接缝

1. **上下文外扩**：发送时把选区周边的环境一起发给模型，让它理解光线和色调
2. **边缘羽化**：选区边界做平滑过渡，不是硬切
3. **接缝色彩匹配**：采样选区内外一圈像素，算出色差，在边缘附近渐进补偿
4. **精确坐标映射**：模型返回的尺寸和比例往往与选区不同，按「盖满 + 居中裁切」取回，**不会拉伸变形**

### 图标为什么是一片白枫叶配红底

图标要在 24px（通知栏）到 192px（桌面）之间都看得清，所以做了两个取舍：

1. **白叶 + 饱和红底**：在 6 套配色里实测「叶子与底色的亮度比」，
   这套在 48 / 32 / 24px 上分别是 2.73 / 2.74 / 2.84，是全部候选里最高的 ——
   小尺寸下最不容易糊成一片。底色用三段渐变（`#ff7048` → `#dc2318` → `#8a0d0a`）避免死板。
2. **叶子占画布高度 60%**：自适应图标只有中间 66.7% 是保证可见的，
   留出余量才不会被厂商的圆形/方形遮罩裁掉花瓣。

叶形用的是标准加拿大枫叶路径，展平成 42 点多边形后内联在 `tools/make-icons.js` 里 ——
构建环境没有 SVG 光栅化器，所以图标生成是**纯 Node 零依赖**的。
网页版 `icon.svg` 用贝塞尔原路径，与生成器的多边形实测叶子掩膜 IoU 0.996，两边看起来是同一片叶子。

### 为什么调参不用重新生成

羽化、色彩匹配、效果强度这些参数是在**合成时**应用的，不是烧进生成结果里的。
所以拖动滑块只是重新合成一遍（毫秒级），完全不调用模型。

调色工具同理，而且它是**逐像素直接算**的：

- **曝光**在**线性光**下做乘除（`×2` 才是真的一档），不是在 gamma 编码值上乘系数 ——
  后者提亮暗部时会偏色
- **对比度**以中灰（0.18 线性）为枢轴，所以「加对比」不会顺带把整张图变亮或变暗
- **饱和度**用 Rec.709 亮度权重求灰度再插值，符合人眼感受（绿色权重最高）
- **色温 / 色调**是 RGB 通道增益，不是套一层颜色滤镜，白色仍然保持中性

选区外的像素**根本不进这个函数**，所以「选区外零改动」是结构性保证，不是靠约束条件凑的。

### 隐私

- 照片只发送到**你自己配置的接口地址**，应用本身不做任何上传
- 可选：发送前对选区外的无关区域打码
- 社交导出预设会自动移除 GPS 定位

## 常见问题

**生成报 `upstream_text_reply`（上游回了一段文字）**

说明当前模型是**对话模型**，不是生图模型。到设置里点「自动检测可用模型」，选标着「可编辑」的。

**报「出图尺寸不符合接口要求」**

不同接口对尺寸有硬性约束（如 OpenAI 要求总像素 ≥ 0.66MP、宽高为 16 的倍数）。
应用会自动修正，若仍报错请把「工作分辨率上限」调低。

**导入大照片后卡住**

把「工作分辨率上限」调到 2048。大照片（如 4800 万像素）解码很吃内存。

**小选区效果不好**

小选区放大后发送，细节上限受原图那一小块的信息量限制。
可以试试换用支持更大输出的模型，或先放大选区再生成。
